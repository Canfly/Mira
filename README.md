# Mira

Открытая обучающая вычислительная система: процессорная архитектура
**CuckooCPU-2** и операционная система **LyraOS-2**, написанные на Rust.

Цель проекта — учебная среда, в которой CPU, ОС и инструменты умещаются в
одну голову, а каждый этап заканчивается чем-то работающим.

## Статус

Текущий этап: **0 / 0.5 — каркас и спецификация ISA**.
Кода CPU пока нет (стабы), заморожена кодировка инструкций.

## Структура

| Путь                 | Что это                                  |
|----------------------|------------------------------------------|
| `crates/mira-cpu`    | модель процессора CuckooCPU-2            |
| `crates/mira-asm`    | ассемблер текста Mira → байты            |
| `crates/mira-emu`    | эмулятор / загрузчик, CLI                |
| `docs/isa.md`        | спецификация системы команд              |
| `docs/memory-map.md` | карта памяти и MMIO                       |
| `docs/roadmap.md`    | план развития по этапам                   |

## Сборка

```sh
cargo build
```

## Запуск (пока заглушка)

```sh
cargo run -p mira-emu
```

## Читать сначала
