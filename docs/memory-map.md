# Mira — карта памяти (CuckooCPU-2)

Версия: 0.1 (Этап 0.5)
Область видимости: единое адресное пространство 64 бита, little-endian.

---

## 1. Регионы

| Начало              | Конец               | Размер   | Что это        | Доступ |
|---------------------|---------------------|----------|----------------|--------|
| `0x0000_0000_0000_0000` | `0x0000_0000_000F_FFFF` | 1 МиБ | RAM (по умолчанию) | RW |
| `0x0000_0000_1000_0000` | `0x0000_0000_1000_000F` | 16 байт | UART (MMIO)  | RW |
| `0x0000_0000_2000_0000` | —                   | 4 байта  | HALT / exit    | W  |

Размер RAM задаётся при создании `Cpu` (по умолчанию 1 МиБ). Этот документ
описывает *начальную* карту; она будет расширяться (таймеры, CLI и т.д.).

---

## 2. RAM

* Диапазон: `[0x0, ram_size)`.
* Чтение/запись в любом размере (1/2/4/8 байт), little-endian.
* Неинициализированная память читается как `0`.
* Выход за границы RAM → trap `bus error`.

Старт RAM — одновременно **reset vector**.

---

## 3. UART (MMIO)

База: `0x1000_0000`.

| Смещение | Адрес         | Имя      | R/W | Поведение                                   |
|----------|---------------|----------|-----|---------------------------------------------|
| `+0x0`   | `0x1000_0000` | UART_TX  | W   | запись младшего байта → вывод символа в stdout |
| `+0x0`   | `0x1000_0000` | UART_RX  | R   | чтение: следующий входной байт или `0` при пустоте (Этап 5) |
| `+0x4`   | `0x1000_0004` | UART_ST  | R   | статус: бит0 = есть входной байт            |

На Этапах 1–4 реализуется только `UART_TX` (запись). Запись 1/2/4/8 байт
выводит **младший** байт.

---

## 4. HALT / exit

Адрес: `0x2000_0000`. Запись любого значения → нормальная остановка
эмулятора (аналог `EBREAK`).

Это временный механизм для Этапов 1–3. С появлением `ecall` (Этап 5)
основным способом выхода станет syscall `exit`, а MMIO HALT останется для
загрузчиков/тестов.

---

## 5. Reset и загрузка

| Параметр            | Значение                          |
|---------------------|-----------------------------------|
| Reset PC            | `0x0000_0000_0000_0000` (настраиваемо) |
| Значение регистров  | все `0`                           |
| `sp` при старте ядра| задаёт загрузчик/ядро (не CPU)    |
| Порядок загрузки    | эмулятор кладёт образ в RAM до старта |

Эмулятор должен поддерживать загрузку по адресу (`load_program(data, addr)`),
чтобы ядро LyraOS-2 могло стартовать не с нуля.

---

## 6. Выравнивание и порядок байт

* Все чтения/записи little-endian.
* Инструкции — по адресам, кратным 4.
* Доступы к данным не обязаны быть выровненными на Этапе 1 (эмулятор
  разберёт по байтам). Позже можно ужесточить.

---

## 7. Будущие регионы (зарезервировано)

| Начало        | Назначение              | Этап |
|---------------|-------------------------|------|
| `0x1000_0010` | Таймер                  | 6+   |
| `0x1000_0020` | Прерывания / PLIC       | 6+   |
| `0x3000_0000` | Диск / образ ФС         | 7+   |

Диапазоны специально разнесены большими промежутками, чтобы не менять
существующие адреса при расширении.
